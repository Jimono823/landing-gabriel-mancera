# Landing · Departamento Gabriel Mancera (R Inmuebles)

Landing estática para la campaña del departamento en Gabriel Mancera, Del Valle Centro.

- `index.html` — la página.
- `assets/styles.css` — estilos (paleta y tipografía de R Inmuebles: League Spartan + Poppins).
- `assets/config.js` — **lo único que normalmente se edita**: WhatsApp, ID del pixel de Meta y (opcional) Formspree.
- `assets/app.js` — botones de WhatsApp, eventos del pixel (`PageView`, `ViewContent`, `Contact`, `Lead`) y formulario.
- `assets/img/`, `assets/video/` — fotos y recorrido optimizados para web.

Se publica con GitHub Pages desde la rama `main`.
